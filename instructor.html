Tips
  • Click any cell to edit it. Press Enter for a line break.
  • ➗ splits a row by adding a sub-row below; ✕ removes a sub-row.
  • Spans sub-rows shows one value across all of a row's sub-rows (darker cells).
  • Reusable answers lets one answer chip fill several blanks, e.g. a repeated category.
  • Your work is saved in this browser automatically. Drop a .json file on the page to import it.
